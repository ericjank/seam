# 六项加固与故障验收

平台保存目标、完整共同文档、版本、批准、任务、交接与证据。项目本地 Connector 调用本端 Agent 完成项目分析、协商、代码实施和测试；平台不使用中心编程模型替两端工作。两端确认同一完整文档后，管理员批准才允许实施。失败后的修复、重新实施与验证仍保留人工确认，最后由管理员手动终止。

## 重试预算恢复

自动推进预算按修订、阶段和参与方分别计算；信息查找任务不消耗普通实施轮次。预算耗尽后持久记录停止点，页面显示具体项目和 Agent。管理员填写原因后可授予新一轮有界重试；新预算从授权时的任务序号开始计算，保留原完整文档和批准指纹。旧授权、重复授权、已变化的阶段和非管理员请求被拒绝。该入口不替代修复方案审批或原有失败重验确认。

协调方的契约提交被拒绝时，也能在同一汇总阶段自动获得下一次有界派发。

## 存活、就绪与空间

`GET /api/health` 验证数据库可读，`GET /api/ready` 使用独立连接完成一笔有界真实写入并提交；只读数据库返回 503。Docker 健康检查使用 ready。探针只维护一条操作记录，不改业务资料；短期缓存和单飞请求限制探针负载。

构建及运行前可执行：

```bash
node scripts/simulation/preflight.mjs --for-build
# 仅当依赖层已存在且可复用时，明确选择缓存构建档位：
node scripts/simulation/preflight.mjs --for-build --cached-build
# 运行预检：
node scripts/simulation/preflight.mjs
```

新构建要求 Docker 可用 12 GiB、宿主机 8 GiB；显式缓存构建档位各 8 GiB，运行档位各 2 GiB。预检不自动删除容器、镜像或数据卷。可选清理仅针对过期、未使用的 BuildKit 缓存。完整模拟在调用模型前自动执行运行预检及可写就绪检查。

## 交接与 HTTP 断言

协议版本升级至 8。Native 失败摘要仅列失败检查、合并相同差异并引用失败命令；原始报告单独完整保留。派发审计留在平台，已进入事实索引的答复不再重复交给 Native。持续会话已审阅同 hash 文档时，实施阶段复用；确认阶段以及检查点丢失或上下文压缩后仍须完整审阅。

完整人类文档中，相同 HTTP 定义共用一个规范编号，各端检查 ID 和执行结果分别保留。固定 Connector 支持 `bodyAssertions` 的字段类型与非空、`headerChecks` 的响应头要求，以及 `emptyBody`。API 错误响应必须明确响应头与正文约束，状态码正确不能单独视为通过。

## 持久续接与实际故障测试

`run-resilient.mjs` 在运行期保留外层测试监督进程。原父进程退出后，从本次私有 bootstrap 恢复同一任务和仍存活的自有 Connector；不新建替代业务会话。控制器和 Connector 用随机进程标记、入口及 PID 共同核对身份，拒绝操作无关进程。私有文件权限为目录 700、文件 600，不进入公开证据。

```bash
SIMULATION_APP_PORT=13139 docker compose -p seam-six-hardening \
  -f docker-compose.simulation.yml up -d --build --wait

SEAM_SIMULATION_URL=http://127.0.0.1:13139 \
SEAM_SIMULATION_SCENARIO=repair-information \
SEAM_SIMULATION_DOCKER_PROJECT=seam-six-hardening \
SEAM_SIMULATION_CHAOS=true \
SEAM_SIMULATION_INJECT_CONTROLLER_EXIT=after_first_approval \
node scripts/simulation/run-resilient.mjs

SEAM_SIMULATION_URL=http://127.0.0.1:13139 \
node scripts/simulation/receipt-boundaries.mjs
```

故障注入仅允许专用 `seam-six-hardening` 项目名及其隔离后缀。完整场景覆盖控制器、原父进程、平台、MySQL 和虚拟提供方 Connector；提交边界测试另外验证 complete 提交前及已提交但未收到 ACK 时重启，保留回执日记并确认无重复执行。该验收不包含整机断电或外层监督进程同时退出。

## 公开证据

`scripts/evidence/export_runtime.py` 排除私有 bootstrap、Git、环境文件并检查实际凭据值。`export_browser_evidence.py` 导出可携带脱敏 trace、独立产品截图及原/公开哈希清单。Trace 保留动作、网络、DOM，内嵌二进制截图替换为占位，防止图像泄露一次性令牌；私有原始文件保留，产品 PNG 单独审阅交付。

公开 trace 可由 Playwright Trace Viewer 打开。完整报告应分别标注真实模型、虚拟端、协议夹具、管理员模拟与浏览器实际点击；不得将合成回执写成真实业务验收。双真实端验收继续搁置。
